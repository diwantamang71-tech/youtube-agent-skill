# youtube-agent-skill

A skill that helps YouTube creators plan and package videos.

## What it does

- **Video ideas:** a list of ideas with hook angles and effort levels
- **Scripts:** spoken-style scripts with a hook, sections, payoff, and one call to action
- **Packaging:** title options, a description, and tags
- **Thumbnails:** thumbnail concepts (text, colors, composition)

It asks for your channel topic, language, audience, video length, and tone, then works in that style.

## Files

- `SKILL.md`: the skill itself (instructions and metadata)

## How to install

Add the repository files to your Claude skills (a folder containing `SKILL.md`), then start a new chat and ask for help with a YouTube video, for example: "Give me 10 video ideas for my cooking channel."
